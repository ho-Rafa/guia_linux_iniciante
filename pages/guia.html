01

Qual Distro Escolher?

No universo Linux, a distro dita quais ferramentas estarão na ponta dos seus dedos. Com foco em segurança ofensiva, vá direto ao ponto.

RECOMENDADO

Kali Linux

Padrão ouro para segurança ofensiva, mantido pela Offensive Security.

  • Centenas de ferramentas pré-instaladas.
  • Base Debian, fácil com apt.
  • Comunidade e documentação enormes.

Parrot OS

Alternativa leve e amigável para máquinas mais modestas.

  • Mais leve para hardware modesto.
  • Bom para o dia a dia.

Ubuntu

Ideal para quem nunca usou Linux e quer estabilidade primeiro.

  • Linux estável e popular.
  • Transição suave antes do Kali.

Dica do Raven!

Nunca instale o Kali direto no seu HD no começo. Use uma Máquina Virtual (VM): evita perder arquivos e permite desfazer desastres em segundos com Snapshots.

02

Como Instalar em VM (o jeito seguro)

Siga este checklist para preparar seu laboratório isolado com VirtualBox e a ISO oficial.

1
Baixe o VirtualBox

Virtualização gratuita. Baixe do site oficial.

2
Baixe a ISO do Kali

Em kali.org/get-kali, escolha Installer (amd64).

3
Crie a VM

Tipo Linux → Debian (64-bit).

4
Pós-instalação: atualize
sudo apt update && sudo apt full-upgrade -y
5
Tire um Snapshot já!

O Snapshot é um "ponto de restauração". Quebrou? Volte em 5 segundos.

03

Como Funciona o Shell

No Kali, o shell padrão é o bash — sua interface direta com o sistema.

Tudo é arquivo

Diretórios, discos e até rede são arquivos numa árvore a partir do root (/).

Root vs sudo

sudo roda com poderes de administrador. Evite usar root pra tudo.

Atalhos essenciais

TAB autocompleta, Ctrl+C interrompe, clear limpa.

Estrutura padrão

Sempre comando -opções argumento (ex.: ls -la /home).

05

Cuidados & Ética

Regras de Ouro

  • Sem autorização = crime: só teste em redes/sites com permissão por escrito.
  • Use Snapshots antes de instalar pacotes desconhecidos.
  • Atualize sempre com apt update && apt full-upgrade.

Comandos Perigosos

Extrema cautela com privilégios elevados:

rm -rf /Apaga todo o sistema sem confirmação!

chmod -R 777 /Destrói as permissões de segurança.

Ferramentas de Pentest

Não aprenda tudo de uma vez. Siga a ordem do iniciante ao avançado:

1º ESSENCIAL
Nmap

Varredura de portas e mapa de rede.

2º WEB
Burp Suite

Proxy que intercepta requisições HTTP/HTTPS.

3º REDES
Wireshark

Análise profunda de pacotes.

4º ENUM
Gobuster

Força bruta em diretórios e subdomínios.
